# clean-state-checklist.md — чек-лист завершения сессии

Прохождение по списку перед коммитом/завершением сессии.

## Код и зависимости
- [ ] `./init.sh` отрабатывает без ошибок.
- [ ] `pytest tests/ -q` зелёный (smoke-тесты).
- [ ] Нет TODO/FIXME без записи в `feature_list.json` или `claude-progress.md`.
- [ ] Нет закомментированного кода «на потом».

## Документация
- [ ] `claude-progress.md` — добавлена запись по сегодняшней сессии.
- [ ] `feature_list.json` — статусы фич актуальны, evidence заполнен у passing.
- [ ] `session-handoff.md` — обновлён (что готово / в работе / сломано / следующий шаг).
- [ ] `README.md` — отражает текущее состояние (если поведение менялось).

## Секреты и артефакты
- [ ] `.env` не закоммичен (проверь `git status`).
- [ ] `outputs/` и `cache/` не закоммичены.
- [ ] HF-токен не в коде и не в коммитах.

## Git
- [ ] Коммит описывает фичу, а не файлы.
- [ ] Репозиторий в запускаемом состоянии (`./init.sh` сработает на свежем чекауте).
